## Detailed explanation

| | list | tuple | set |
|--|------|-------|-----|
| Ordered | Yes | Yes | No |
| Mutable | Yes | No | Yes |
| Duplicates | Allowed | Allowed | Removed |
| Hashable | No | Yes, if its items are | No (`frozenset` is) |
| `x in ...` | O(n) | O(n) | O(1) average |

## Example in a pipeline

```python
batch = []                                   # list: rows accumulate in order
batch.append(("2026-10-01", "north", 150))   # tuple: a fixed record
batch.append(("2026-10-01", "south", 230))

already_loaded = {("2026-10-01", "north")}   # set of tuple keys
to_load = [r for r in batch if (r[0], r[1]) not in already_loaded]
print(to_load)
```

```text
[('2026-10-01', 'south', 230)]
```

## Common mistakes

1. Checking membership against a large list inside a loop.
2. Expecting a set to preserve order.
3. Thinking a tuple is "always hashable": `(1, [2])` is not, because it contains a list.
