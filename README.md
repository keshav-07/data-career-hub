# Data Career Hub

A structured learning and interview-preparation website for Data Engineers.
Static [Astro](https://astro.build) site with Markdown/MDX content collections,
[Pagefind](https://pagefind.app) static search and deployment to Cloudflare Workers Static Assets.

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # astro build + pagefind index -> dist/
npm run preview
```

See `docs/` for architecture, content authoring and deployment notes.
